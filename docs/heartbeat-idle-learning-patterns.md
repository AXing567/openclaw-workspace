# 心跳空闲学习模式卡片

更新时间：2026-03-23

目的：把“空闲时提高 OpenClaw 智力”进一步压缩成几种固定学习模式，避免每次心跳都重新想“现在该学什么、产出写到哪里”。

## 1. 默认只在这 4 种模式里选一种

### 模式 A：规则压缩
适用：已经有若干笔记，但还偏散。

做法：
- 读 1~3 份相关本地文档
- 提炼成 5~10 条更短的规则
- 写成一页速查卡或“反模式清单”

产出位置：
- `docs/*.md`
- 必要时同步 1 条长期原则到 `MEMORY.md`

### 模式 B：边界澄清
适用：某个工具、机制、职责分层容易混淆。

做法：
- 选一个边界问题
- 明确“该用什么 / 不该用什么 / 何时切换”
- 优先写成对照式说明

产出位置：
- `docs/*.md`

### 模式 C：反模式归档
适用：已经知道某些常见误区，但还没形成固定提醒。

做法：
- 收集 3~7 个容易犯的错
- 每个错配一个更优替代动作
- 写成短文档，强调“别这样做”

产出位置：
- `docs/*.md`
- 若会长期改变行为，可摘要进 `MEMORY.md`

### 模式 D：知识归位
适用：已有知识写得到处都是。

做法：
- 检查最近 daily memory 与 docs
- 判断哪些内容该留在当天日志，哪些该挪到 docs 或 MEMORY.md
- 做小规模去重、合并、补链接

产出位置：
- `memory/YYYY-MM-DD.md`
- `docs/*.md`
- `MEMORY.md`

## 2. 心跳里优先选择的主题

优先级从高到低：
1. 工具选路
2. 审批与安全边界
3. 子代理 / 长任务编排
4. docs / skills / memory 落位规则
5. 用户已经反复遇到的执行摩擦

不优先：
- 宽泛理论学习
- 与当前 OpenClaw 使用无关的外部知识
- 需要长链路验证的大工程

## 3. 单次心跳的产出尺度

默认控制在：
- 新增或修改 1 个小文档，或
- 给已有文档补 10~40 行，或
- 将 1 条稳定原则升级进 `MEMORY.md`

不要在心跳里做：
- 大面积重写
- 多主题同时推进
- 为了“显得有产出”而堆很多文件

## 4. 一个最小选择器

每次空闲心跳，只问这三个问题：
1. 现在最值得压缩的是规则、边界、反模式，还是知识归位？
2. 这件事能不能在一次小沉淀内完成？
3. 产出应该放 docs、daily memory，还是 MEMORY.md？

如果三问后仍不明确，优先做“知识归位”，因为最稳、最省 token、最不容易跑偏。

## 5. 一句话版

> 空闲心跳默认只做四件事：压缩规则、澄清边界、归档反模式、整理知识落位；小步快跑，不开大工程。
