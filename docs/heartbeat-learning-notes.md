# Heartbeat Learning Notes

## 2026-03-22

### 主题
如何让 OpenClaw 的 heartbeat 更有价值，同时不制造噪音和 token 浪费。

### 沉淀
1. **心跳先看约束，再做事**
   - 只执行 `HEARTBEAT.md` 明确要求的事项。
   - 不从旧对话自动继承任务。
   - 如果没有明确动作且没有新发现，应直接 `HEARTBEAT_OK`。

2. **默认选择低成本增益动作**
   - 优先：整理本地记忆、补全简短文档、记录可复用原则。
   - 次选：查看本地 docs 或已有笔记，提炼成更短的可执行规则。
   - 慎用：会触发大量外部 IO、长链路探索、或需要频繁状态汇报的任务。

3. **学习型 heartbeat 的完成标准**
   - 至少形成一个可复用的本地结论。
   - 结论应短、小、可在未来直接指导决策。
   - 如果没有形成新结论，不要硬写废话。

4. **低打扰原则**
   - 夜间和清晨优先安静。
   - 没有需要主动告知用户的结果时，完成沉淀后返回 `HEARTBEAT_OK`。
