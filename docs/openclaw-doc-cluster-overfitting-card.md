# OpenClaw doc-cluster-overfitting card

## 默认判断
- 连续沉淀短卡时，如果大量新卡都围绕同一个局部对象打补丁，文档体系会出现“簇内越来越密、簇外长期空白”的过拟合倾向。
- 这不是单张卡质量问题，而是整体覆盖面失衡：局部越来越细，整体却没更聪明。

## 识别信号
- 最近多张卡彼此强依赖，脱离前文就难判断价值。
- 新卡解决的是越来越细的边角误判，而不是更高频或更通用的选路问题。
- 读者会感觉“这里写得特别密，但别的地方还是空的”。

## 调整原则
- 优先补高频、跨任务复用的判断口，而不是继续深挖一个已很密的簇。
- 写新卡前先问一句：这张卡是在扩大全局覆盖，还是只是在一个热点区继续加像素？
- 如果答案偏后者，本轮宁可跳过，也不要继续局部加密。

## 何时适合收手
- 当最近几轮新卡已经明显形成同主题簇时，先停下来，让文档体系保留空白区等待更值得补的对象。
- heartbeat 不负责把一个局部对象打磨到百科全书级别。

## 简写规则
- 短卡沉淀要防局部过拟合：别把一处写成高分辨率，别处还全是空白。
