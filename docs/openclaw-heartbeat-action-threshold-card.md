# OpenClaw heartbeat action-threshold card

## 核心判断
- heartbeat 轮次里，不是“能做点什么”就一定要动手；要先判断这个动作是否已经超过心跳该有的颗粒度。
- 默认阈值：**轻读、轻写、轻整理可以直接做；跨主题整理、批量修订、结构性重排应停止在记录判断，不继续展开。**

## 可直接做的动作
- 读 1~2 份现有短文档
- 新增一张短卡片
- 给已有规则补一条缺失边界
- 把模糊经验压缩成一句可执行规则

## 应该停下的动作
- 顺着一个点继续补出一串相邻卡片
- 为了统一风格而批量改历史文档
- 开始做目录重组、归档、重命名
- 需要同时核对多份材料才能继续的扩展写作

## 判断方法
1. 这轮是否只有一个清晰判断点？
2. 修改是否局限在一个文件或极少数文件？
3. 如果现在停下，产物是否已经独立成立？

只要有一个问题回答为“否”，就更适合收手，留到明确任务再做。

## 目的
- 防止 heartbeat 从“低打扰知识沉淀”滑成“后台偷偷开项目”。
- 保持每轮产出小、硬、可累计。

## 一句话版
> heartbeat 里真正重要的不是持续动作，而是知道哪里该停。
