# OpenClaw heartbeat boundary-escalation card

## 默认判断
- heartbeat 里的空闲学习任务，默认只做“边界更清楚”的补位，不做“能力更大”的扩张。
- 优先沉淀：什么时候该升级工具、什么时候该停止试探、什么时候不该把 heartbeat 变成正式项目。

## 适合压缩成短卡的内容
- 轻量工具与重型工具的切换阈值。
- 本地整理与外部查证的分界线。
- 单轮 heartbeat 的升级信号：什么算值得继续，什么算该收手。

## 不适合在 heartbeat 展开的内容
- 需要大量案例、长链验证或完整教程的主题。
- 需要连续多轮施工才能体现价值的体系化改造。
- 为了“学习”而学习、但本轮不能形成明确判断规则的材料堆积。

## 常见失误
- 只会补工具清单，不补使用边界，结果知道能做什么，却不知道何时不该做。
- 一发现新主题就横向扩写成文档集，失去 heartbeat 的轻量性。
- 把“继续研究”当成产出，实际上没有留下任何可复用判断。

## 简写规则
- heartbeat 学习优先补边界，不优先补百科。
