# OpenClaw 心跳卡片：主题簇过密时先停手

更新时间：2026-03-27

问题：
- 某一类 heartbeat 主题一旦连续产出多张卡片，后续很容易进入“还能写，但边际收益已经很低”的状态。

结论：
- 当同主题簇已经存在较多相邻卡片时，下一轮默认动作不应继续细分，而应先判断该主题是否已经进入饱和区。
- 饱和区内，最优动作通常是停手、合并、或切换主题，不是继续扩写。

饱和信号：
1. 新卡片和已有卡片共享大量标题词与判断词。
2. 新结论主要是在重述“少读、少扰、少重复、补空白”这类已稳定规则。
3. 新文档无法新增明确动作，只能补措辞或例子。
4. 读完已有卡片后，仍很难说出这张新卡究竟解决了哪个新问题。

默认动作顺序：
1. 先停 10 秒问：这是新维度，还是旧结论再包装？
2. 若是旧结论再包装：不新建卡片。
3. 若只是局部补充：并入已有卡片或总览文档。
4. 只有在确实新增独立判断维度时，才单独建新卡。

反模式：
- 因为“还能想到标题”就继续写
- 把主题密度误当成知识深度
- 规则库里同义卡越来越多，检索成本反而上升

一句话版：
> 心跳学习不是把一个主题榨干，而是在边际收益变低时及时停手。
