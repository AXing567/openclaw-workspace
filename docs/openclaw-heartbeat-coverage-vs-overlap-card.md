# OpenClaw 心跳卡片：覆盖空白优先于主题重叠

更新时间：2026-03-27

问题：
- 心跳学习如果总在同一主题簇里补相近卡片，虽然每张都略有不同，但整体会出现“覆盖面变窄、重叠度升高”的问题。

结论：
- 心跳选题时，优先补“规则库里的空白点”，而不是继续细分已经很密集的主题。
- 当某一前缀主题下已经有多张相邻卡片时，新增前先问一句：这张卡片是在补新维度，还是只是在换一种说法？

判断规则：
1. **补空白，可以写：**
   - 之前没有明确规则的情境
   - 会影响选路、审批、安全边界的新问题
   - 能减少未来误判的独立判断维度
2. **高重叠，先停：**
   - 只是把已有规则换个标题再说一遍
   - 只是对同一结论做更细碎拆分
   - 新卡片无法提供新的动作规则，只是增强措辞
3. **遇到重叠主题时，优先动作：**
   - 合并到已有卡片
   - 改写索引文档/总览文档
   - 转去补另一个规则空白

简单启发式：
- 如果新卡片不能回答一个“之前答不了的新判断问题”，就大概率不值得单独新建。

反模式：
- 在同一主题簇里连续生成多张近义卡片
- 让规则库看起来变多了，但决策覆盖面没有扩大
- 为了保持产出节奏而堆叠低增量文档

一句话版：
> 心跳学习要优先扩覆盖面，不要把已有主题越切越碎。
