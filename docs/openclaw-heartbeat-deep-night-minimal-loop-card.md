# OpenClaw 心跳卡片：深夜心跳最小闭环

更新时间：2026-03-28

问题：
- 当 HEARTBEAT.md 要求“空闲时学习并沉淀”时，深夜时段容易陷入一种伪勤奋：虽然每次动作都很小，但连续做多轮“读一点、补一点、再扩一点”，最终仍然形成高频干扰和无边界扩写。

结论：
- 深夜 heartbeat 默认采用“最小闭环”策略：一轮只做一次读取判断 + 一次本地沉淀 + 停止。
- 若本轮已经形成可见产物（短日志、短卡、规则补丁任一即可），则视为完成，不继续追求额外增量。

执行规则：
1. 先判断是否确有小缺口；没有就直接静默。
2. 若有缺口，只允许一个闭环产物，不做第二轮派生阅读。
3. 产物以可见、可验证、可复用为标准，不以篇幅为标准。
4. 完成后默认退出，不因为“现在很安静”而追加新主题。

边界：
- 这条规则只约束 heartbeat 场景，不约束用户显式交办的正式任务。
- 若存在明确告警、故障、待修复阻塞，则应优先处理实际问题，不受“最小闭环”限制。

一句话版：
> 深夜 heartbeat 做成一个闭环就够了：判断一次，落地一次，然后停。
