# OpenClaw heartbeat doc-gap card

## 默认判断
- heartbeat 空闲学习时，优先补“还缺但已知边界清晰”的短卡，而不是重复改写已有主题。
- 判断文档空缺时，先看最近几轮沉淀覆盖了哪些维度：读、写、范围、标题、正文、密度；再找仍缺的决策点。

## 怎么判断是值得补的空缺
- 这个判断点会在后续 heartbeat 或日常工具使用中反复遇到。
- 不需要大规模查资料，只靠现有规则和近期经验就能压缩成卡。
- 文件名能直接表达“对象 + 判断点”，读标题就知道解决什么犹豫。

## 低价值选题信号
- 只是把已有短卡换一种说法重写。
- 主题太大，一张卡装不下，只能写成泛泛原则。
- 只描述概念，不改变后续具体动作选择。

## 高价值选题信号
- 能减少下一次 heartbeat 的选题犹豫。
- 能减少工具使用中的默认误判或不必要试探。
- 能作为其他短卡的前置分流规则。

## 简写规则
- 先盘点最近已写什么，再补一个仍会反复遇到的缺口；不为“看起来勤奋”重复造卡。
