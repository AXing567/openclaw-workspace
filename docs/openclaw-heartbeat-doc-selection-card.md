# OpenClaw Heartbeat Doc Selection Card

## 空闲学习时优先沉淀什么
- 先补“决策前置卡片”，而不是扩写概念百科
- 优先写能减少下一次犹豫的短卡：选路、停手、降级、升级条件
- 只补当前卡片体系里缺的一环，避免同主题重写

## 文档选题顺序
1. 哪个判断还要临场现想？先写那个
2. 哪个错误最容易重复犯？先写那个
3. 哪个卡片能和现有卡片互相补位？先写那个
4. 如果新卡片只是旧卡片的改写版，就别写

## 本地沉淀的好形态
- 标题一眼能看出用途
- 3~5 条规则就能覆盖多数场景
- 明确“何时用 / 何时不用 / 何时停止”
- 能和 `tool-routing`、`execution-modes`、`heartbeat-work` 这些卡片拼起来用

## heartbeat 里的完成标准
- 新卡片补上一个之前未显式写清的判断点
- 内容短、可复用、不会迫使后续再读长文档
- 写完即可停，不继续扩成体系工程
