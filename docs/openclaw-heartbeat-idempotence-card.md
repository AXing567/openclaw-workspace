# OpenClaw heartbeat idempotence card

## 默认判断
- heartbeat 是高频入口，同一主题会反复出现；每轮默认先判断“这次是否真的新增了信息”，再决定是否动手。
- 如果本轮只能重复昨天已经写过的同类短卡，宁可不写，也不要换个标题重炒一遍。

## 如何判断值得写
- 新卡片解决了一个此前没被单独压缩的判断点。
- 新卡片能明显减少下一轮 heartbeat 的犹豫、重复阅读或重复决策。
- 新卡片与已有卡片的差异，不只是换措辞，而是新增边界、默认动作或停止条件。

## 何时该停
- 当你发现自己只是把“范围控制 / 文档补位 / 密度自检”换一种说法时，就该停。
- 当本轮没有形成新的可复用判断点时，直接返回 `HEARTBEAT_OK`，比制造新文件更好。

## 常见失误
- 为了显得有产出，给旧内容套新标题。
- 把“可复用判断”写成“本轮做了什么流水账”。
- 以为 heartbeat 必须每次都写文件，结果把文档库堆成近义反复。

## 简写规则
- heartbeat 先查重：没新增判断，就别写。
