# OpenClaw Heartbeat Idle Learning Card

更新时间：2026-03-23

## 目的
当 HEARTBEAT.md 仅要求“空闲时自行学习提高 OpenClaw 智力并沉淀到本地”时，需要把任务收敛成低打扰、低 token、可累计的本地工作，而不是每次都展开大工程。

## 默认决策顺序
1. 先看当前是否真空闲
2. 若空闲，优先整理已有知识，而不是先扩张搜索范围
3. 产出应是 workspace 内可见文本：卡片、规则、边界说明、速查笔记
4. 若工具受限，直接降级为整理已知经验，不反复试探环境

## 心跳下适合做的事
- 把分散经验压缩成一页短卡
- 整理工具选路原则
- 补充失败模式与降级路径
- 归纳 docs / memory / skills 的职责边界
- 修正文档里容易误解的表述

## 不适合在心跳里做的事
- 启动长链路外部调研
- 频繁调用高成本 API
- 大规模目录遍历或环境试探
- 明明没有新发现，却重复汇报旧结论

## 本次补充的细化原则
### 1. 优先写“决策卡”，不是长报告
心跳的最好产出，通常是以后能反复复用的短规则。

### 2. 优先补“容易踩坑的边界”
例如：
- 哪些情况该用 browser 而不是 web_fetch
- 哪些情况该直接 edit 而不是开子代理
- 哪些情况 heartbeat 应安静结束

### 3. 以可验证文本为完成标准
不是“我学到了”，而是：
- workspace 里多了一份文档
- 文档能被下次会话直接复用
- 内容足够短，能在受限环境下快速读取

## 一句话原则
Heartbeat 学习不是表演勤奋，而是持续把零散经验压缩成可复用的本地规则。
