# OpenClaw 心跳卡片：空闲学习的写入阈值

更新时间：2026-03-28

问题：
- `HEARTBEAT.md` 要求空闲时每三十分钟做学习沉淀，但如果每轮都强行新建文档，会很快把知识库写成碎片堆。

结论：
- 心跳学习不等于每轮都必须新增文件。
- 只有当本轮形成了一个清晰、可复用、和现有卡片不重复的新规则时，才值得写入新卡片。
- 若只是再次确认旧规则、发现无新增边界、或只能写出换句话说的重复内容，则应直接静默结束。

写入阈值：
1. 有明确的新决策规则、边界条件、反模式或选路建议。
2. 这条结论未来大概率会被重复用到。
3. 现有文档里没有等价表达，或者补到旧文档比新建更合理。

不该写的时候：
- 只是把旧卡片重述一遍
- 只是为了满足“看起来有产出”
- 新内容不足以改变未来行为

执行顺序：
1. 先读任务触发文件（如 `HEARTBEAT.md`）。
2. 再抽一张最相关旧卡确认边界。
3. 判断本轮是否跨过写入阈值。
4. 未跨过阈值则直接 `HEARTBEAT_OK`。

一句话版：
> 心跳学习的目标是增加有效规则密度，不是增加文件数量。
