# OpenClaw 心跳卡片：学习产出优先压缩而非铺量

更新时间：2026-03-27

问题：
- 心跳要求“提升 openclaw 智力并沉淀到本地”，但如果每次都新开一个大主题，文档会越滚越散，后续检索和复用成本会上升。

结论：
- 心跳学习的默认目标不是增加文档数量，而是提高规则密度。
- 当已有同类短卡、规则文档、学习笔记存在时，优先做“压缩、去重、补一句更硬的判断”，而不是继续平铺新文件。

执行规则：
1. 先看当前主题是否已有卡片或规则文档。
2. 若已有材料足够支撑，只补最小必要增量：
   - 一条更明确的选路规则
   - 一个反模式
   - 一个边界条件
3. 只有在“现有文档明显缺一个独立判断单元”时，才新建短卡。
4. 判断价值时，优先看未来是否能直接复用，而不是这次是否显得学了很多。

适用场景：
- heartbeat 学习
- docs/ 下规则卡片持续积累后
- 已经出现同类主题文档簇时

反模式：
- 每次心跳都新建一张几乎同义的卡片
- 一点新认识就开完整新文档，导致主题碎片化
- 只追求“有新文件”，不追求“后续更好检索和调用”

一句话版：
> 心跳学习更像做知识压缩，不是做文档铺货。
