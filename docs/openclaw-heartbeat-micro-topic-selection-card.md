# OpenClaw heartbeat micro-topic selection card

## 默认判断
- heartbeat 只要求“空闲时学习并沉淀到本地”时，选题要尽量小：一轮只补一个可独立成立的判断点。
- 优先选“刚好比已有卡片再细一层”的题目，而不是重新开大类。

## 怎么选
- 先看最近已沉淀的卡片都在讲什么默认判断。
- 找其中仍然容易犹豫的一步：比如“何时停”“怎么命名”之后，就轮到“怎么选足够小的题目”。
- 题目应能用一句话说清价值，不需要配套第二、第三篇才能成立。

## 合格信号
- 标题具体，能看出对象和判断点。
- 正文能压缩成默认判断 + 边界 + 常见失误。
- 写完后能直接降低下次 heartbeat 的犹豫成本。

## 不合格信号
- 题目大到必须枚举很多子场景。
- 写着写着开始变成方法论总纲或目录规划。
- 需要先补很多背景知识，这说明题目还不够小。

## 简写规则
- heartbeat 选题：优先补最小缺口，不开新宇宙。
