# OpenClaw 心跳卡片：白天空闲时的轻量学习优先级

更新时间：2026-03-27

问题：
- `HEARTBEAT.md` 要求空闲时每三十分钟学习并沉淀，但白天时段如果每次都挑大主题，容易把心跳做成重任务。

结论：
- 白天空闲心跳应优先选择“单点、高复用、可在一轮内闭合”的微主题。
- 最优主题通常不是新开大坑，而是把已有经验再压缩一层，形成更短、更稳的选路卡片。

选题顺序：
1. 先选最近反复出现的判断点
2. 再选容易机械化误用的默认动作
3. 最后才是补新的大块知识面

适合的微主题：
- 某个工具什么时候足够、什么时候该升级到更重工具
- 某类 follow-up 为什么不该默认全展开
- 哪些提示只是背景噪音，不该劫持主任务路径
- 某个常见动作的停止条件和跳出条件

不适合的主题：
- 需要多轮外部调研才能得出结论的问题
- 需要大规模整理现有文档的重构型任务
- 只是“看起来重要”，但短期不会提高执行质量的泛知识

执行规则：
1. 一轮心跳只解决一个微判断点。
2. 产物尽量压成一张短卡，能被未来直接复用。
3. 若已有同主题卡片，优先补充或重写，不重复开散点文件。
4. 没有形成新判断时，宁可不写，也不要为了完成次数硬造新卡。

一句话版：
> 白天空闲心跳，优先做能在一轮内闭合的微学习，而不是借学习名义开新工程。
