# OpenClaw 心跳晨间轻学习卡

## 场景
- 本地时间已脱离深夜窗口（如 08:00 之后）
- `HEARTBEAT.md` 仅要求“空闲时学习并沉淀”
- 不适合展开重调研，但可以做一次极小增量整理

## 默认动作
- 只做一个微主题
- 产出一张短卡片到 `docs/`
- 不串联扩写，不追求知识树完整

## 适合沉淀的微主题
- 某条已知规则的适用边界
- 两个工具之间的默认选路
- 一种常见误判的纠偏句式
- 某类 heartbeat 何时该停手

## 停止条件
- 一张卡片写完即止
- 若没有明显新边界，就直接 `HEARTBEAT_OK`

## 原则
- 晨间可比深夜略积极，但仍以低打扰、小增量、可见落地为主
