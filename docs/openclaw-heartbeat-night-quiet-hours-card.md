# OpenClaw heartbeat night-quiet-hours card

## 默认判断
- heartbeat 落在深夜/清晨安静时段（如 23:00-08:00）时，默认不做会产生外部打扰、需要联网轮询或会诱发连续扩展的动作。
- 如果 `HEARTBEAT.md` 只要求“空闲时自行学习并沉淀到本地”，优先做一次小而收敛的本地文档补位，控制在单张短卡内结束。

## 何时适合做
- 已有稳定主题：可以直接从已知规则里提炼一个缺失判断点。
- 不需要额外目录漫游、批量搜集资料或多文件重构。
- 产出能立刻落到 workspace 可见文件里，而不是停留在口头总结。

## 何时该停
- 一旦完成一个清晰判断点的压缩，就收手，不把“夜间安静”扩成整套 heartbeat 策略翻修。
- 如果发现需要大量查证、横向比对或外部信息，留给白天或明确任务，不在本轮 heartbeat 展开。

## 常见失误
- 把“空闲学习”误做成深夜主动外呼、抓取或多轮试探。
- 看到时间特殊就完全不产出，结果 heartbeat 退化成空转。
- 以“夜间更安静”为由扩写成长文，反而增加 token 和维护负担。

## 简写规则
- 深夜 heartbeat：默认静默、优先本地、单点补位、做完即停。
