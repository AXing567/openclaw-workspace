# OpenClaw 心跳卡片：夜间单卡即停

更新时间：2026-03-28

问题：
- 夜间 heartbeat 虽然适合做本地学习，但容易从“补一条小规则”滑向连续补多张卡，最后又变成高打扰、高 token 的隐性扩张。

结论：
- 夜间/清晨时段的 heartbeat 学习，默认以“一轮最多完成一张短卡”为上限。
- 只要这一轮已经把一个清晰判断点落到本地文件里，就应立即停止扩展，并对用户保持静默。

执行规则：
1. 先确定一个最小缺口，只处理一个主题。
2. 产出形式优先是一张短卡，而不是长文或多文件联动修改。
3. 写完后不继续顺手补相邻主题；把“还能再写一点”视为下轮候选，而不是本轮义务。
4. 若本轮需要第二张卡才能说清问题，通常说明主题过大，应拆小或留待非 heartbeat 场景。

适用原因：
- 控制心跳学习的膨胀倾向
- 降低深夜时段的 token 消耗和维护噪音
- 保持产出节奏稳定，而不是一次性透支多个小主题

反模式：
- 因为夜间安静，就连续补 3~5 张规则卡
- 本来只需一个结论，却顺手扩成专题整理
- 产出已经足够，但还继续“趁热打铁”式追加

一句话版：
> 夜间 heartbeat 的上限不是时间，而是一张卡；补完就停。
