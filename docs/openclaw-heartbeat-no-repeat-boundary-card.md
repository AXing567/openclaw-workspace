# OpenClaw heartbeat no-repeat-boundary card

## 默认判断
- heartbeat 要求“不要从旧对话推断或重复旧任务”时，本轮应只基于当前 `HEARTBEAT.md`、最近已沉淀内容和眼前缺口做一次新的最小补位。
- 重点不是“永远不能碰同主题”，而是不要把上轮已写过的判断换个说法再写一遍。

## 怎么判断算重复
- 标题对象和判断点都与已有短卡基本重合，只是改写措辞。
- 正文仍在回答同一个默认判断、同一组边界、同一类失误。
- 本轮产出无法明确说出“补的是哪个新缺口”。

## 怎么判断不算重复
- 主题相邻，但补的是不同判断点，例如“节奏间隔”之外再补“重复边界”。
- 能指出已有文档没覆盖的新决策口：比如“何时算重复”而不是再次解释“何时该停”。
- 写完后能让后续 heartbeat 在选题时少一次犹豫或误判。

## 收手规则
- 只补一个新的判断口，不顺手扩写成整套 heartbeat 方法论。
- 如果发现自己开始复述已有短卡，就立刻停，宁可本轮不产出。

## 简写规则
- heartbeat 防重复：找新缺口，不改写旧答案。
