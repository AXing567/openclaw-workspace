# OpenClaw 心跳卡片：08:00 前默认只做本地沉淀

更新时间：2026-03-27

场景：
- heartbeat 命中 23:00-08:00 安静时段。
- `HEARTBEAT.md` 仅要求“空闲时学习并沉淀到本地”。

规则：
- 08:00 前的 heartbeat，默认只做本地可见沉淀，不展开外部检查、联网轮询、批量搜索或需要持续跟进的动作。
- 这类时段的最优解是：补一条小规则、压缩一个判断点、提交后结束。

为什么：
- 既满足“空闲时学习”的要求，又避免把清晨 heartbeat 做成高打扰、高扩散任务。
- 能把时间段约束显式化，减少每次都重复判断“现在算不算该安静”。

执行模板：
1. 选一个未补齐的小判断点。
2. 写入 `docs/*.md` 或当天 `memory/*.md`。
3. 若无紧急风险或需用户决策事项，则返回 `HEARTBEAT_OK`。

一句话版：
> 08:00 前 heartbeat 的默认工作模式，不是外扩，而是本地小步沉淀。
