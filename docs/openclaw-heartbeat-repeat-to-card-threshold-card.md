# OpenClaw heartbeat repeat-to-card threshold card

## 默认判断
- 当 heartbeat 学习已经连续几轮都围绕同一簇小规则补卡时，下一轮先判断“是否还存在新的最小缺口”。
- 如果继续写只是在把同一意思换个说法、换个时间点、换个标签重述，就应停止，直接 HEARTBEAT_OK。
- 只有当新产物能新增一个明确可执行判断边界时，才值得继续补一张卡。

## 适用场景
- 最近几轮 heartbeat 已连续产出多张彼此相邻的节奏/边界卡片。
- 当前想补的内容与已有卡片高度近似，差异主要在措辞而不是决策规则。
- 需要给未来 heartbeat 一个“什么时候别再写了”的停手阈值。

## 判定问题
- 这次新增内容，能否改变下一轮 heartbeat 的动作选择？
- 如果删掉这张卡，是否会丢失一个真实的判断边界？
- 是否已经开始围绕同一主题做低收益密集沉淀？

## 收手信号
- 新想法只能作为已有卡片中的一句补充，而不值得独立成卡。
- 再写下去会进入“卡片解释卡片”的自我堆叠。
- 当前主题已形成足够闭环，继续写不会明显提升执行质量。

## 简写规则
- 同簇主题连续补几轮后，若没有新的动作边界，就停，不为凑学习而再造一张卡。
