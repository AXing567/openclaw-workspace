# OpenClaw Heartbeat Scope Card

## heartbeat 里该收多窄
- 只做当前轮能闭环的小事
- 产出要能单独成立，不依赖后续连载
- 单轮最好只补一个判断点，不同时开多个主题

## 什么时候说明显做宽了
- 一张短卡开始拆成多层体系
- 为了补一条规则，又顺手开出三条支线
- 当前产物必须再写两篇配套文档才有用
- 开始为了完整性而不是为了实用性继续扩展

## 控制范围的方法
- 先写“这轮只解决哪个犹豫点”
- 写完后用停止卡反查：现在停下是否已经有用
- 如果后续还有可写点，留给下一轮 heartbeat

## 一句话原则
heartbeat 追求的是连续小闭环，不是一次性铺满地图。
