# OpenClaw heartbeat single-output card

## 默认判断
- 一轮 heartbeat 空闲学习默认只产出一个清晰结果：一张短卡、一次小修订，或一条可验证补充。
- 目标是让每轮都有可见沉淀，但不会扩成连续施工。

## 为什么重要
- heartbeat 是巡航节奏，不是全天候项目模式。
- 单轮只保留一个主输出，能降低跑偏、复读和 token 膨胀。
- 后续回看 daily memory 时，也更容易判断这一轮到底补了什么。

## 适用边界
- 适合：规则卡片、边界说明、命名规范、工具选路经验这类小颗粒沉淀。
- 不适合：需要改多处文档、统一重构、横向清洗一批旧文件的任务。

## 常见失误
- 名义上是 heartbeat，实际上一个回合里同时补三四个点，导致主题散掉。
- 产出前先大面积搜集，最后没有真正落地文件。
- 想“顺手再补一点”，把原本收敛的一轮拖成小工程。

## 收手信号
- 当前卡片已经回答一个明确判断点。
- 再往下写开始进入相邻主题，而不是深化同一主题。
- 需要举更多例子才能撑内容时，通常说明该停了。

## 简写规则
- heartbeat 单轮：一个主输出，写完就停。
