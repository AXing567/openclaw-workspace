# OpenClaw heartbeat single-pass card

## 默认判断
- heartbeat 单轮默认只做一个可闭合的小动作：补一张短卡、修一段表述、沉淀一个判断点。
- 目标不是“趁空闲多做一点”，而是稳定积累，不把心跳做成连续施工。

## 如何判断是单轮可闭合
- 主题明确，能用已有上下文直接写完。
- 产出限制在一个文件或一处小改动内，不依赖额外探索。
- 完成后能清楚回答“这轮到底补了什么”。

## 适合的动作
- 把一个常见判断压缩成卡片。
- 给已有文档补一句缺失边界。
- 记录一次方法选择的简洁结论。

## 不适合的动作
- 借 heartbeat 开始系统性重构或成组补文档。
- 为了找题材而大范围翻目录、跑命令、做多轮查证。
- 一个判断点没写完，又顺手扩成相关专题集合。

## 收手信号
- 当前文件已经形成“默认判断 + 边界/失误 + 简写规则”或同等密度结构。
- 如果再写下去只是补同义句、举更多近似例子，就该停。

## 简写规则
- heartbeat 单轮：只做一件小事，写完就结束。
