# OpenClaw heartbeat small-gap-skip card

## 默认判断
- heartbeat 虽然写着“每三十分钟一次”，但它更像节奏提醒，不是必须逢点交作业的 KPI。
- 如果上一次空闲学习刚完成不久，而且没有出现新的明确补位点，本轮默认安静跳过，不为凑频次重复造卡。

## 何时值得继续做
- 距离上一次沉淀已经明显拉开，且能一眼看出一个新的判断点缺口。
- 新缺口能在单张短卡里闭合，不需要重新翻一遍整套文档。
- 本轮产出不会与最近 1-2 次 heartbeat 的主题高度重叠。

## 何时该跳过
- 只有“差不多又过了三十分钟”这一条理由，没有新的主题或新判断点。
- 刚刚做过同类 heartbeat 卡片，再做只会换个标题重复同一套原则。
- 继续写会把 heartbeat 变成机械刷文档，而不是有密度的补位。

## 常见失误
- 把“三十分钟一次”理解成无条件必须产出。
- 为了不空转，硬把旧卡片换皮再写一遍。
- 明知没有新信息密度，还是重复扩写相邻主题。

## 简写规则
- 小时间隔 heartbeat：先问“有没有新缺口”；没有就跳过，不刷存在感。
