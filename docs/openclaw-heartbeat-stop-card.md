# OpenClaw Heartbeat Stop Card

## 什么时候该直接停
满足任一条，就可以结束本轮 heartbeat：
- 本轮已经产出一个清晰、可见、可复用的本地沉淀
- 新内容只是对已有卡片换句话说，没有新增判断价值
- 受工具边界限制，继续探索只会变成重复试探
- 当前可做的最好动作只是“记一条日志说明边界”
- 再继续会把 heartbeat 变成长任务或大工程

## 停止前自检
- 这次是否真的新增了信息密度？
- 产物是否在 workspace 内可直接看到？
- 是否避免了外部动作和无谓试探？
- 是否已经记录到当日日志？

## 原则
heartbeat 的目标不是“尽量多做”，而是“低成本持续变聪明”。
能收就收，别把空闲维护做成黑盒施工。
