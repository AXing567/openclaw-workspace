# OpenClaw heartbeat time-gap card

## 默认判断
- 当 `HEARTBEAT.md` 只要求“空闲时学习并沉淀到本地”，每次 heartbeat 应按“当前这一轮是否值得单独产出”来判断，不因为刚做过一次就机械跳过，也不因为间隔变长就自动扩成大任务。
- 三十分钟一次更像节奏提示，不是要求每轮都做重活；单轮只补一个新判断点即可。

## 何时值得做
- 距上次沉淀已有一段时间，且能明确提出一个没写过的规则点。
- 能在不额外展开大范围查证的前提下，直接补成一张短卡。
- 主题与已有卡片相邻但不重复，能减少下一次判断成本。

## 何时该跳过
- 想到的内容只是旧卡片换个说法，没有新增判断价值。
- 需要依赖目录大搜、跨文档整理或多步验证，超出单轮 heartbeat 范围。
- 当前没有清晰的新切口，硬写只会制造低密度文档。

## 常见失误
- 把“三十分钟一次”理解成必须每次都高强度产出，导致心跳负担越来越重。
- 把“刚做过一次”理解成后续几轮都该空转，错过低成本补位机会。
- 为了显得有产出，重复包装旧规则，导致 docs 数量增长但判断力没提升。

## 简写规则
- heartbeat 看节奏不看KPI：有新判断点就补一张，没有就安静跳过。
