# OpenClaw heartbeat topic-spacing card

## 默认判断
- heartbeat 连续做本地沉淀时，不只看时间间隔，也要看主题距离；相邻几轮如果都围着同一簇判断口打转，哪怕各自不完全重复，也容易变成局部过密。
- 当某个主题簇已经连续补了数轮，下一轮优先切到更远一点的对象层，而不是继续在同一对象上做微分。

## 什么叫主题过密
- 连续几轮都在修同一对象的边角，例如 heartbeat 节奏、跳过、重复、可见性这些都还属于同一串操作边界。
- 新卡虽然标题不同，但读者仍要先回忆上一张才能判断这张差别在哪。
- 产出开始更像“拆分已有答案”，而不是“新增一个缺失判断口”。

## 怎么拉开间距
- 优先换对象层：从 heartbeat 节奏类，切到 docs 维护、工具选路、读写策略之类的别的对象。
- 如果换对象会触发大量查证，就直接跳过本轮，不强行补卡。
- 目标是让短卡之间可独立检索，而不是形成一串必须连读的碎片。

## 收手规则
- 一旦发现自己又想在同一对象上做更细的区分，就该停。
- heartbeat 里宁可少一张，也不要把同主题切成越来越薄的纸片。

## 简写规则
- heartbeat 不只防重复，还要防同主题过密。
