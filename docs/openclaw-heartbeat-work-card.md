# OpenClaw Heartbeat Work Card

## heartbeat 里优先做什么
- 小步、低打扰、可见的本地沉淀
- 整理已有规则、经验、边界
- 压缩成长文档的短卡片
- 记录本次学习产出到当日日志

## heartbeat 里避免什么
- 展开大工程
- 高频轮询后台状态
- 为了找资料反复试探受限 shell/目录
- 在没有明确收益时做外部 API 写操作
- 把同一件事换个说法重复沉淀

## 决策顺序
1. 先看 `HEARTBEAT.md` 是否有明确任务
2. 若是“空闲时学习”，优先整理本地已知知识
3. 若工具受限，进一步降级为经验卡片/边界说明
4. 若没有新产出空间，就回 `HEARTBEAT_OK`

## 完成标准
- 至少有一个 workspace 内可见产物，或明确判断本轮无新增价值
- 不制造新的黑盒流程
- 不依赖口头“我记住了”
