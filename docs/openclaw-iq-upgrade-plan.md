# OpenClaw 智商增强计划

更新时间：2026-03-20

## 目标
把 OpenClaw 从“会聊天”提升为“会稳定调用正确上下文、工具和流程”的系统。

## 四步执行

### 第一步：系统学习官方核心文档并本地沉淀
- 已开始：`/tools`
- 下一批：
  - `/tools/web`
  - `/tools/plugin`
  - `/tools/skills`
  - `/tools/exec-approvals`
  - `/tools/firecrawl`
- 交付物：
  - `docs/openclaw-*.md` 系列学习笔记
  - `MEMORY.md` 中稳定原则级记忆

### 第二步：重构记忆体系
- 压缩 `MEMORY.md` 为长期原则库
- 区分 daily log / long-term memory / docs knowledge
- 识别噪音、重复项、临时项，进行收敛
- 交付物：
  - 优化后的 `MEMORY.md`
  - 记忆分层说明文档

### 第三步：整理高频 Skills
- 识别你的高频任务模式
- 能 skill 化的任务尽量固化
- 交付物：
  - 候选 skill 清单
  - 至少 1-3 个高价值 skill 草案或改进建议

### 第四步：输出实战升级设计
- 给出目录结构、知识沉淀规则、记忆策略、技能策略、工作流策略
- 交付物：
  - 一份针对当前工作区的 `OpenClaw 智商增强方案`
