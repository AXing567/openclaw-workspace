# OpenClaw Memory Recall Card

## 什么时候必须先跑 `memory_search`
涉及以下任一类问题时，先检索记忆：
- 之前做过什么
- 过去的决定、结论、方案取舍
- 日期、时间、里程碑
- 某个人的身份、偏好、习惯
- 待办、承诺、提醒、后续跟进

## 推荐流程
1. 先 `memory_search`
2. 命中后，只对必要片段用 `memory_get`
3. 低置信度时明确说“我查过记忆，但把握不高”
4. 需要用户验证时，附 `Source: <path#line>`

## 不该怎么做
- 凭模糊印象直接回答“你之前说过...”
- 为了省一步跳过 `memory_search`
- 一上来整文件读取大量 memory 内容

## 判断边界
- 当前即时任务、纯技术事实、公开知识问答 → 不一定需要记忆检索
- 只要答案依赖“这个用户/这个项目/之前发生过什么” → 先检索记忆
- 主会话可读长期记忆；共享/群聊上下文要更谨慎，避免泄露不该带出的个人信息
