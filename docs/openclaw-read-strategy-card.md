# OpenClaw Read Strategy Card

## 默认读法
- 先读最小必要范围，不一上来整文件通读
- 先找最可能承载答案的文件，再逐步扩展
- 已有短卡能回答的，就别退回长文档

## 什么时候少读
- 只是确认一个规则、路径、边界
- 已知文件名和大致位置
- 只是为了支撑一次局部编辑

## 什么时候多读一点
- 规则互相冲突，需核对上下文
- 文件是高风险配置，误改代价高
- 你怀疑已有摘要卡片遗漏了关键限定条件

## 常见浪费
- 每轮都把同一批文件全读一遍
- 明明只缺一条规则，却把相关文档全扫一遍
- 已经有短卡，还回去读原始长文档凑安心感

## 一句话原则
先够用，再扩展；先定位，再通读。
