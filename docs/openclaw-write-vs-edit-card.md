# OpenClaw Write vs Edit Card

## 默认判断
- 改已有文件里的局部内容：先 `edit`
- 新建文件：用 `write`
- 需要整文件重写且你明确掌握完整目标内容：才用 `write`

## 什么时候优先 `edit`
- 只改一小段
- 需要保留文件其余内容原样不动
- 希望改动范围可控、可审计
- 文档或配置文件已有主体，只是在其上补一段

## 什么时候可以 `write`
- 文件本来不存在
- 目标就是完全替换整个文件
- 内容短，重写比精确替换更不容易出错

## 常见失误
- 为了图省事用 `write` 覆盖已有长文件
- 没先读文件就盲改，导致 `edit` 精确匹配失败
- 其实只是补一行，却把整文件重写成新版本

## 一句话原则
能小改就别整覆盖；能精修就别整页重刷。
